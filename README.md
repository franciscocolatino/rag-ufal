# rag-ufal

Assistente que responde perguntas sobre documentos públicos da UFAL (regimento,
editais, PPC, calendário acadêmico) em português, citando documento e página.

> Em construção — Semana 1: pipeline de RAG pela CLI.

## Setup

```bash
uv sync                 # instala dependências (torch CPU-only)
# coloque os PDFs em data/raw/
```
